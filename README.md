# Aurora

**Clear reports, brighter outcomes.**
Aurora is a free, open-access web application for structured neuroradiology reporting and score
calculation in neurodegenerative disorders (visual rating scales, small vessel disease burden,
atrophy and movement-disorder calculators), with reports in English and Portuguese.

**Use Aurora:** https://aurora-report.com

## Versions

| Version | What it is | Code |
|---|---|---|
